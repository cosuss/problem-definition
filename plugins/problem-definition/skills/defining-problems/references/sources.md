## 자료 간 충돌과 이 스킬의 처리

| 충돌 | 처리 |
|---|---|
| 가설 지향(맥킨지 p.10 "해결책을 미리 헤아려 봄") vs 솔루션 금지(문제의 탄생 p.7) | 해결책을 `보류한 해결책` 칸으로 옮긴다. 금지가 아니라 순서 |
| 분해 가능(MECE·로직트리) vs 사회 문제는 분해 불가(Rittel) | MECE는 빠진 곳 없이 훑는 용도로만 쓰고 분해한 원인 구조를 정답으로 내지 않는다. 확정본은 길들여진 문제만. 사악한 문제는 렌즈를 바꿔 한 번 더 그린다 |
| 계획이 먼저(Delmar) vs 행동과 약속이 먼저(Sarasvathy) vs 시행착오 불가(Rittel p.163) | 네 축 진단으로 가른다. 각 문헌이 자기 적용 조건을 본문에 적어 두었다 |
| 체념한 고객: 유효한 경로(Sequoia Hard Fact) vs 가짜 문제 징후(문제의 탄생 p.54) | 지금 비용을 치르고 우회 행동이 있는가로 가른다 |
| 발생·탐색·설정형 vs Sequoia 3유형 | 축이 다르다(조직 안의 기준 대 고객의 태도). 1:1로 대응시키지 않는다 |
| 이미 치르는 비용(문제의 탄생) vs 해결에 낼 돈(진형석) | 둘 다 본다. 절실성 질문에 둘 다 있다 |
| 규모가 클수록 강함(문제의 탄생 p.61) vs 넓고 심각하면 큰 회사 몫(진형석) | 넓이와 깊이를 따로 적고, 넓고 깊으면 "왜 아직인가"를 요구 |
| 의향을 묻지 않는다(기존 규칙) vs 가격을 불러 보게 한다(진형석) | 의향을 물었으면 대체재와 반복으로 다시 묻는다. 의향 답은 가장 가벼운 등급 |
| 방어력은 팀이 가진 것(문제의 탄생) vs 문제의 난이도(진형석) | 비대칭성 칸에 둘 다 적는다 |
| 문제 정의는 객관적인가 | 현상은 사실로 고정하고(규칙 2), 프레임은 선택임을 드러낸다(규칙 3) |
