# 농업 밸류체인 이슈 트리: 유통 단계 (루트 아래 11개 층)

> 상태: 잠정본. 근거 논문은 DBpia 검색 결과의 제목·저자·nodeId만 확인했고(`[확인: 서지]`), 초록·본문은 읽지 않았다. 논문의 주장과 수치는 `[가정]`이다.
> 적용 규칙: `plugins/problem-definition/skills/defining-problems/references/trees.md`
> 짝 문서: `2026-10-14-agri-valuechain-issue-tree-production.md`, `2026-10-14-agri-issue-tree-overview.md`

## 1. 설계

- 생산 판과 같은 분할 수(2·5·3·3·2·4·3·2·5·3·4)로 11개 층을 내려간다. L1~L2는 같고 L3부터 유통 쪽으로 갈라진다.
- ★ 한 가지만 끝까지 내려간다 `[가정]`. 생산 판이 "생산성"을 골랐으므로 이번에는 "비용 구조"를 골라 대비시켰다.
- 분할 비율은 구조상의 균등 배분이다. 가중치는 붙이지 않았다.
- 한계: 대형유통업체 납품 조건, 계약재배·출하약정은 DBpia 검색 결과가 거의 없었다. 처음 구상한 "수익·분배 → 대형마트 거래조건" 가지는 근거 부족으로 접고 비용 구조 쪽으로 옮겼다.

## 2. 트리

```
루트 L0  농업 밸류체인: 어디서 가치가 만들어지고, 어디서 새거나 한쪽에 쏠리는가를 구조적으로 파악한다

L1  기준: 흐름 vs 흐름을 받치는 것
    ├ ★주활동 (50%)
    └  지원활동 (50%)

L2  기준: 농산물의 이동 순서 (5분할)
    ├  투입 (20%)   ├  생산 (20%)   ├  수확 후 관리 (20%)   ├  가공 (20%)
    └ ★유통·소비 (20%)

L3  기준: 밸류체인 분석 질문 (3분할)
    ├  효율: 얼마나 빠르고 손실 없이 흐르나   (33%)
    ├ ★비용 구조: 무엇에 얼마가 드나         (33%)
    └  수익·분배: 남은 몫을 누가 가져가나    (33%)

L4  기준: 비용이 생기는 기능 (3분할)
    ├ ★물류(운송·보관)                       (33%)
    ├  거래(경매·중개·수수료)                (33%)
    └  정보(가격·수급 정보의 생산과 활용)    (33%)

L5  기준: 보관·운송 온도 조건 (2분할)
    ├  상온                                   (50%)
    └ ★저온(콜드체인)                        (50%)

L6  기준: 저온 물류의 구간 (4분할)
    ├  산지 예냉·저장                        (25%)
    ├  산지 → 도매시장 운송                  (25%)
    ├ ★도매시장 내 취급                      (25%)
    └  소비지 배송                           (25%)

L7  기준: 도매시장 취급의 구성 요소 (3분할)
    ├ ★시설(정온경매장·저온창고)            (33%)
    ├  운영(인력·절차)                       (33%)
    └  제도(규정·수수료)                     (33%)

L8  기준: 시설의 설치 구역 (2분할)
    ├ ★경매장(정온경매장)                    (50%)
    └  저장·집하 구역                        (50%)

L9  기준: 도입·운영 비용 항목 (5분할)
    ├  건설                                   (20%)
    ├  냉각 설비                             (20%)
    ├ ★에너지(전력)                          (20%)
    ├  인력                                   (20%)
    └  유지보수                              (20%)

L10 기준: 에너지 절감 방법 (3분할)
    ├ ★설비 효율(기술)                       (33%)
    ├  운영 방식(제어·스케줄)                (33%)
    └  에너지원 전환(신재생 등)              (33%)

L11 기준: 냉각 설비의 구성 (4분할)
    ├ ★압축기·냉매                           (25%)
    ├  단열·외피                             (25%)
    ├  제상·열교환                           (25%)
    └  제어·모니터링                         (25%)
```

결론 리프: 농업 → 주활동 → 유통·소비 → 비용 구조 → 물류 → 저온 → 도매시장 내 취급 → 시설 → 정온경매장 → 에너지 비용 → 설비 효율 → 압축기·냉매

## 4. MECE 자가 점검

못 통과한 곳을 먼저 적는다.

- **L3 분석 질문**: 효율·비용·분배는 서로 연결된 지표라 완전한 ME가 아니다 `[가정]`.
- **L4 비용 기능 3분할**: "정보" 비용은 물류·거래 비용에 흡수되어 별도로 셈하기 어렵다. 층위가 다소 다르다.
- **L5 상온/저온**: 냉장·냉동·예냉 등 온도대가 셋 이상일 수 있어 2분할로 단순화했다.
- **L6 저온 물류 구간**: 산지 예냉·저장과 소비지 배송은 L2 단계(수확 후 관리, 소비)와 겹친다.
- **L9 비용 항목**: 건설과 냉각 설비는 초기 투자로 묶일 수 있다. 5분할을 맞추려고 쪼갰다 `[가정]`.
- **L11 설비**: 단열·외피는 냉각 설비가 아니라 건축물의 일부일 수 있다. 층위가 섞였다.
- **경로의 성격**: L9 이후는 문제 정의보다 설비 공학에 가깝다. 문제 정의가 목적이면 L6 또는 L7에서 멈추는 것이 맞다.
- **통과**: L1, L2, L7, L8은 기준이 하나이고 ME·CE를 만족한다.
