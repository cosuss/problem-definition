# 농업 이슈 트리: 설계 경과와 두 판의 비교

> 문서: `2026-10-14-agri-valuechain-issue-tree-production.md`(생산 판), `2026-10-14-agri-valuechain-issue-tree-distribution.md`(유통 판)

## 1. 요구가 바뀐 경과

같은 주제의 요구가 세 번 구체화되었다. 해석을 다시 맞춘 기록으로 남긴다.

| 판 | 요구 해석 | 구조 |
|---|---|---|
| v1 | 루트 아래 노드 10개 이상, 동등 층위는 반반 | 2 → 4 → 8로 이분할. 노드 14개 |
| v2 | 노드 수가 아니라 선 개수 | 루트 → 10선(각 10%) → 20선(각 5%). 선 30개 |
| v3 | 층이 10개 이상 | 이분할로 10개 층. 한 가지만 내려감 |
| v4(현재) | 밸류체인·분석 방법, 분할 수가 층마다 2·3·4·5로 변함, 가중치 없음, 10개 층 이상 | 11개 층. 생산 판과 유통 판 |

v1~v3의 초기 트리(농업 인력, 농지, 기후·자연환경, 농업 환경·지속가능성, 생산 기술, 수확 후 관리·안전, 국내 유통·가격, 수출·통상, 농정·직불제, 농촌 공동체)는 이 저장소에 따로 싣지 않았다.

## 2. 두 판의 공통 틀

- L1: 주활동 / 지원활동 (Porter 가치사슬). 50:50
- L2: 주활동 5분할(투입·생산·수확 후 관리·가공·유통·소비), 지원활동 4분할(금융·기술·인력·제도)
- L3: 분석 질문 3분할(생산성·비용 구조·수익·분배)
- L4 이하: 선택한 단계에서 행동 단위까지 내려간다.

## 3. 두 판 나란히 보기

| | 생산 판 | 유통 판 |
|---|---|---|
| L3 선택 | 생산성 | 비용 구조 |
| 중간 층 | 작물군 → 시설 → 환경 제어 | 기능 → 저온 → 도매시장 취급 |
| 말단 | 영상·분광 측정 | 압축기·냉매 |
| 근거 밀도 | 중간 | 말단 쪽은 한 호에 편중 |
| 문제 정의로의 연결 | L6~L8에서 가능 | L6~L7에서 가능, 이후는 설비 공학 |

## 5. 남은 일

- 투입·소비 단계는 DBpia에서 근거를 찾지 못했다 `[비움]`.
- 대형유통업체 납품 조건, 계약재배·출하약정은 DBpia 검색 결과가 거의 없었다. 한국농촌경제연구원 보고서 등 다른 출처를 찾아야 한다.
- 가공·수확 후 관리·투입 단계는 아직 그리지 않았다.
- 인용 논문의 초록·본문을 읽어 `[가정]`을 `[확인]`으로 올리지 않았다.
