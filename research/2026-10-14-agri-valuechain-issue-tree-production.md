# 농업 밸류체인 이슈 트리: 생산 단계 (루트 아래 11개 층)

> 상태: 잠정본. 근거 논문은 DBpia 검색 결과의 제목·저자·nodeId만 확인했고(`[확인: 서지]`), 초록·본문은 읽지 않았다. 논문의 주장과 크기는 `[가정]`이다.
> 적용 규칙: `plugins/problem-definition/skills/defining-problems/references/trees.md`
> 짝 문서: `2026-10-14-agri-valuechain-issue-tree-distribution.md`, `2026-10-14-agri-issue-tree-overview.md`

## 1. 설계

- 루트 아래 11개 층. 분할 수는 2 → 5 → 3 → 3 → 2 → 4 → 3 → 2 → 5 → 3 → 4로 층마다 다르고, 같은 부모 아래 형제는 동등한 비율(50·33·25·20%)이다.
- L1~L2는 밸류체인 자체, L3은 밸류체인 분석 질문, 그 아래는 선택한 단계를 행동 단위까지 내린다.
- 11층을 전부 펼치면 읽을 수 없어서 ★ 한 가지만 끝까지 내려가고 형제는 그 층에서 멈춘다. 가지 선택은 작성자의 판단이다 `[가정]`.
- 분할 비율은 구조상의 균등 배분이다. 실제 문제 크기가 같다는 뜻이 아니다 `[가정]`. 가중치는 붙이지 않았다.

## 2. 트리

```
루트 L0  농업 밸류체인: 어디서 가치가 만들어지고, 어디서 새거나 한쪽에 쏠리는가를 구조적으로 파악한다

L1  기준: 흐름 vs 흐름을 받치는 것 (Porter 가치사슬의 주활동 / 지원활동)
    ├ ★주활동: 농산물이 물리적으로 흐르는 단계 (50%)
    └  지원활동: 흐름을 가능하게 하는 것 (50%)

L2  [주활동] 기준: 농산물의 이동 순서 → 5분할
    ├  투입(종자·비료·농약·기계)            (20%)
    ├ ★생산(재배·사육)                      (20%)
    ├  수확 후 관리(선별·저장·포장)          (20%)
    ├  가공                                  (20%)
    └  유통·소비                             (20%)
    [지원활동] 기준: 지원의 종류 → 4분할
    ├  금융  ├ 기술(R&D·이전)  ├ 인력(노동·교육)  └ 제도(정책·규제)  (각 25%)

L3  [생산] 기준: 밸류체인 분석 질문 → 3분할
    ├ ★생산성: 투입 대비 얼마를 만드나       (33%)
    ├  비용 구조: 무엇에 얼마가 드나         (33%)
    └  수익·분배: 남은 몫을 누가 가져가나    (33%)

L4  [생산성] 기준: 작물군 → 3분할
    ├  식량작물(쌀·맥류 등)                 (33%)
    ├ ★원예특작(채소·과수·화훼)             (33%)
    └  축산                                  (33%)

L5  [원예특작] 기준: 재배 환경의 통제 여부 → 2분할
    ├ ★시설(온실·하우스)                    (50%)
    └  노지                                  (50%)

L6  [시설] 기준: 재배 공정 순서 → 4분할
    ├  재배 설계·육묘                        (25%)
    ├ ★환경 제어                            (25%)
    ├  생육·병해충 관리                      (25%)
    └  수확·선별                             (25%)

L7  [환경 제어] 기준: 제어 루프의 단계 → 3분할
    ├  센싱(측정)                            (33%)
    ├ ★판단(의사결정)                       (33%)
    └  구동(장치 작동)                       (33%)

L8  [판단] 기준: 판단 근거 → 2분할
    ├  규칙·경험 기반                        (50%)
    └ ★데이터·모델 기반(예측)               (50%)

L9  [데이터·모델 기반] 기준: 모델 수명주기 → 5분할
    ├ ★데이터 수집                          (20%)
    ├  전처리·품질 관리                      (20%)
    ├  학습·모델링                           (20%)
    ├  검증                                  (20%)
    └  현장 적용·운영                        (20%)

L10 [데이터 수집] 기준: 데이터 출처 → 3분할
    ├  환경 데이터(온·습도, CO₂ 등)         (33%)
    ├ ★작물 생육 데이터                     (33%)
    └  경영·농작업 기록                      (33%)

L11 [생육 데이터] 기준: 측정 방식 → 4분할
    ├ ★영상·분광 촬영                      (25%)
    ├  접촉식 센서                           (25%)
    ├  수기 조사                             (25%)
    └  원격(드론·위성)                       (25%)
```

결론 리프: 농업 → 주활동 → 생산 → 생산성 → 원예특작 → 시설 → 환경 제어 → 판단 → 데이터 기반 → 데이터 수집 → 작물 생육 데이터 → 영상·분광 측정

## 4. MECE 자가 점검

못 통과한 곳을 먼저 적는다.

- **L2 주활동 5분할 (CE 약함)**: "투입" 근거를 찾지 못했다. 유통과 소비를 한 노드로 묶은 것은 층위가 다르다. 분리하면 6분할이 되어 20% 균등이 깨져서 묶었다.
- **L2 지원활동 4분할**: 인력과 제도는 고용허가제·계절근로자제에서, 금융과 제도는 정책금융에서 겹친다. ME가 약하다.
- **L3 분석 질문 3분할**: 생산성·비용·수익은 서로 연결된 지표라 배타적이지 않다. 같은 사실을 보는 세 관점이다 `[가정]`.
- **L4 작물군**: 임산물·특용작물·양봉 등 경계 사례가 있다. "원예특작"이 두 개념을 묶었다.
- **L9 수명주기**: 운영과 검증이 순환해 순서가 고정이 아니다. 5분할은 작성자 구분이다 `[가정]`.
- **통과**: L1, L5, L6, L7, L8, L10은 기준이 하나이고 ME·CE를 만족한다. L11은 CE가 약하다.
- 이 트리는 한 경로의 깊이만 보여 준다. 비용 구조·수익 분배와 다른 단계는 펼치지 않았다.
